First time on this computer

  1. Download and extract

    Save the ZIP, then extract the complete Light-Magic folder into Documents or another writable folder. Open START HERE.html inside for these instructions offline.

  2. Install Python 3.12, once

    Skip this if 64-bit Python 3.12 is already installed. Choose the official installer for your computer; finish its installation before the next step.

    Python for Mac ↗ Python for Windows ↗

    The Mac installer supports Intel and Apple Silicon. The Windows installer is for 64-bit Intel/AMD PCs. Python is installed separately from the Light Magic ZIP.

  3. Open the setup launcher

    Mac

    Set up Light Magic.command

    Windows

    Set up Light Magic.bat

    Double-click the file for your computer. Stay online and keep its window open while it installs the voice packages. It then opens the controller automatically.

    If macOS will not launch the .command file, open Terminal in the extracted folder and run: sh "Set up Light Magic.command".

  4. Open your session

    Use Chrome or Edge on that computer and open http://127.0.0.1:8765/#session.

    Start rehearsal to check the inputs. For real lights, connect this computer to Eos over Ethernet, enter the desk’s IP and confirm the console session before Go live.

Next time

Open Start Movement Gesture.command on Mac or Start Movement Gesture.bat on Windows. The installed models run offline; you do not need to repeat setup.

What is in the download?

The full controller source, camera models, the standard English speech model, the Movement Lab 3D preview, Mac and Windows launchers, and an offline start guide. First-time setup installs the Python voice packages online. The larger Enhanced speech model is optional and installs separately.

Can I bring my current cue mappings?

Yes. Close Light Magic on both computers, then copy profile.json into the new Light-Magic folder. For learned motions, also copy custom-motions.json. Your personal settings are not part of the public download. Confirm the console and devices again on the new computer.

Can I try it without installing?

The browser rehearsal simulates the lights without installing anything. To send real Eos commands, run the controller on a computer connected to the console. Browser rehearsal
