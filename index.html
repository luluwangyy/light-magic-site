Set up the bridge computer

Install Light Magic on the computer connected to Eos. You’ll need Python 3.10 or newer and access to the private GitHub project. For speech on macOS, use Python 3.12 or 3.13.

  1. Bridge computer
  2. OSC over TCP
  3. ETC Eos
Download project ZIP ↗
Installation steps
  1. Extract the ZIP. Sign in to GitHub before downloading, then extract the files on the bridge computer.
  2. Start the launcher. Open Start Movement Gesture.bat on Windows or Start Movement Gesture.command on macOS. On macOS you can also run sh "Start Movement Gesture.command" from the extracted folder. Keep the launcher running.
  3. Open the controller. In Chrome or Edge on the bridge computer, open http://127.0.0.1:8765/. This address points to the computer you’re using.
  4. Add speech if needed. While online, open Setup speech recognition.bat on Windows or Setup speech recognition.command on macOS. Restart Light Magic. Speech recognition runs offline after setup.

Going live

  1. Preview

    Choose your inputs and check recognition while output is paused.

  2. Check the desk

    Confirm the Eos console and show. Test each mapped cue or level and verify the visible result.

  3. Enable output

    Go live after the checks. Press Esc to pause automatic output.

Console controls and troubleshooting

Map a channel level. Choose Output → Channel level, enter the channel and percentage, then enable and save the mapping. In Session, open the mapping’s console test, choose Send test level live, and confirm the visible result.

Adjust a channel manually. Confirm Eos and the show. Pause automatic output, then open Console → Set a channel level.

Check a spoken phrase. Open Speech → Typed phrase test. Check phrase shows the mapping. Send matched output live runs a separate manual test. Use the microphone to check recognition.

Keep one bridge running at a time. Starting or reconnecting keeps automatic output paused. Testing with macOS and physical Eos hardware is still pending.
