From practice to performance

A clear path to live.

  1. Preview

    Choose your inputs and start a session. Check recognition without sending lighting commands.

  2. Check

    Confirm the intended Eos console and show. Test each mapped cue or channel level and confirm what you see.

  3. Go live

    Enable automatic output when the checks are complete. Pause output at any time with Escape.

Get started

Your laptop.
Your lighting desk.

Use Chrome or Edge and Python 3.10 or newer. For speech on macOS, use Python 3.12 or 3.13. Connect your laptop to Eos when you’re ready to control the lights.

Download the project ↗

The source repository is private. Sign in to GitHub with an account that has access to download it.

  1. Download and extract

    Download the ZIP and extract it to a folder on your computer.

  2. Launch the app

    On Windows, open Start Movement Gesture.bat. On macOS, open Start Movement Gesture.command or run sh "Start Movement Gesture.command" in Terminal from the extracted folder.

  3. Add speech, if you need it

    With internet access, open Setup speech recognition.bat on Windows or Setup speech recognition.command on macOS. On macOS, you can also run sh "Setup speech recognition.command" in Terminal from the extracted folder. Restart the app after setup. Speech recognition then runs offline.

  4. Open the local controller

    With Light Magic running on this computer, visit 127.0.0.1:8765. Choose Camera, Speech only, or Camera + speech, allow browser access to the inputs you use, and start a rehearsal.

Shared live control

For shared live control, run Light Magic on one computer connected to Eos. Operators open its private HTTPS address in Chrome or Edge and sign in with the venue’s credentials. One browser controls the show at a time.

Shared bridge setup

Built to run locally.

The bridge sends cues and channel levels to Eos over OSC/TCP. In a shared session, camera recognition runs in the browser and microphone audio goes to the bridge over the private HTTPS connection.

To map a gesture or phrase to a level, select Output → Channel level, enter the channel and percentage, then enable and save the mapping. In Session, open the mapping’s console test, choose Send test level live, and confirm the visible result before going live.

For a manual adjustment after confirming Eos and the show, use Console → Set a channel level while automatic output is paused.

For speech troubleshooting, open Speech → Typed phrase test. Check phrase shows the mapping, and Send matched output live runs a separate manual console test. Use the microphone to check recognition.

Keep one bridge copy running at a time. Starting or reconnecting keeps automatic output paused. A full test with macOS and Eos hardware is still pending.
