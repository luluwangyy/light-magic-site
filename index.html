Set up the bridge computer

Install Light Magic on the one computer connected to Eos. You’ll need Python 3.10 or newer and access to the private GitHub project. For speech on macOS, use Python 3.12 or 3.13.

Bridge installation steps

  1. Download and extract

    Sign in to GitHub, download the project ZIP, and extract it on the bridge computer.

  2. Start the launcher

    On Windows, open Start Movement Gesture.bat. On macOS, open Start Movement Gesture.command or run sh "Start Movement Gesture.command" in Terminal from the extracted folder. Keep the launcher running.

  3. Open the local controller

    After the launcher starts, open http://127.0.0.1:8765/ in a normal Chrome or Edge window on the bridge computer. This address always points to the computer you’re using.

  4. Add speech, if you need it

    With internet access, open Setup speech recognition.bat on Windows or Setup speech recognition.command on macOS. Then restart Light Magic. Speech recognition runs offline after setup.

Set up a private HTTPS link for other computers

Built to run locally.

The bridge sends cues and channel levels to Eos over OSC/TCP. In a shared session, camera recognition runs in the browser and microphone audio goes to the bridge over the private HTTPS connection.

To map a gesture or phrase to a level, select Output → Channel level, enter the channel and percentage, then enable and save the mapping. In Session, open the mapping’s console test, choose Send test level live, and confirm the visible result before going live.

For a manual adjustment after confirming Eos and the show, use Console → Set a channel level while automatic output is paused.

For speech troubleshooting, open Speech → Typed phrase test. Check phrase shows the mapping, and Send matched output live runs a separate manual console test. Use the microphone to check recognition.

Keep one bridge copy running at a time. Starting or reconnecting keeps automatic output paused. A full test with macOS and Eos hardware is still pending.
