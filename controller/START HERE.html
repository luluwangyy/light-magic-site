Light Magic

This is the complete controller for Mac and Windows. The full download includes the camera models and standard English speech model. First setup needs internet to install Python voice packages.

First time

  1. Extract the whole ZIP. Put the Light-Magic folder in Documents or another writable folder. Keep all its files together.
  2. Install 64-bit Python 3.12 if needed. Choose the official Mac installer (Intel or Apple Silicon), or Windows installer (Intel/AMD 64-bit). Complete the installer, including pip and the Python launcher on Windows.
  3. Double-click the setup file for your computer.
    Mac: Set up Light Magic.command
    Windows: Set up Light Magic.bat
    Stay online and keep its window open. It creates the local environment, installs speech packages and starts the controller. Do this once.
  4. Open http://127.0.0.1:8765/#session in Chrome or Edge on this computer. Choose your inputs and Start rehearsal. For real lighting, connect to the Eos network, enter the current desk IP and confirm the console session before Go live.

If macOS cannot launch the .command file, open Terminal in this folder and run sh "Set up Light Magic.command". If a controller is already running, close its launcher before running setup.

After setup

Use Start Movement Gesture.command on Mac or Start Movement Gesture.bat on Windows. No repeat setup is needed. Keep the launcher window open while using the controller. Installed recognition models work offline.

Bring your saved show

Close the controller on both computers. Copy profile.json from your old controller folder to this one. Copy custom-motions.json too if you have learned motions. These personal files are not included in the public download. Reconfirm the devices and console on the new computer.

The optional Enhanced speech model installs separately. See README.md for details, live control and troubleshooting.

中文使用说明
  1. 先完整解压。把整个 Light-Magic 文件夹放到“文稿”或其他可写入的位置，不要直接在压缩包里运行脚本。
  2. 安装一次 64 位 Python 3.12。上面提供 Mac 和 Windows 的官方安装链接。如果电脑已经安装，可以跳过。
  3. 双击首次设置脚本。Mac 用 Set up Light Magic.command，Windows 用 Set up Light Magic.bat。保持联网并保留弹出的窗口，它会自动配置语音依赖，然后启动程序。
  4. 在这台电脑的 Chrome 或 Edge 打开 本地控制器。先选输入方式并 Start rehearsal。要控制真实灯光，需要连接 Eos 网络、填写控制台 IP，确认会话后再 Go live。

以后 Mac 用 Start Movement Gesture.command；Windows 用 Start Movement Gesture.bat。不需要重复设置，已安装的识别模型可离线使用。

要沿用旧电脑的 cue 映射，关闭两边的程序后复制 profile.json。自定义学习动作还需复制 custom-motions.json。这些个人设置不在公开下载包中。

Physical Mac operation and the venue’s console connection still need an on-site check.
